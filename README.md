# uragami-todo

机の上に置いた裏紙に殴り書きするような、その日だけの TODO を置いておく macOS 用のデスクトップアプリです。ディスプレイに貼るポストイットのように、画面の端に開いたままにして使います。

データは 1 つの JSON ファイルだけで、アプリの外から読み書きできます。AI エージェント（Claude Code など）やスクリプトにタスクを書き換えさせると、開いているアプリにそのまま反映されます。

## 特徴

- **紙 1 枚ぶんだけ持つ**: 日付ごとの履歴は持たず、「いまの状態」を 1 ファイルに置きます。翌日はファイルごと書き換えて使う想定です
- **AI やスクリプトから読み書きできる**: データは人が読める形の JSON です。外で書き換えると、アプリは 1.5 秒以内に読み直します
- **置き場所を選べる**: iCloud Drive や Dropbox の中に置けば、複数の Mac で同じ TODO を使えます
- **操作は少なく**: チェック、並べ替え、子タスクへの分解、明日に回す、だけです

## 使い方

- チェック欄をクリック: 完了 / 未完了の切り替え
- タイトルをダブルクリック: 書き換え（Enter で確定、Esc で取り消し）
- 左端のつまみ（⋮⋮）をドラッグ: 並べ替え（子タスクは親の中で並べ替え）
- タスクの行にマウスを乗せると右端に出る「＋」: 下に子タスクの入力欄を開く（Enter で追加、もう一度「＋」か Esc で閉じる）
- タスクを右クリック: 「明日に回す」（「明日やる」の欄では「今日に戻す」）と「削除」。子タスクがあるタスクを消すときは、子タスクも消えることを確かめるダイアログが出ます
- 子タスクを右クリック: 「削除」
- 一番下の「＋」の入力欄: タスクを足す

## 設定

設定は、データファイルの場所だけです。次のファイルに書きます。

```
~/Library/Application Support/co.obentoba.uragami-todo/config.json
```

```json
{
  "dataPath": "~/Library/Mobile Documents/com~apple~CloudDocs/uragami-todo/todo.json"
}
```

- `dataPath` には、データファイルのパスを書きます。先頭の `~/` はホームフォルダに置き換えます
- 設定ファイルが無いとき、または `dataPath` が空のときは `~/Documents/uragami-todo/todo.json` を使います
- 設定ファイルはマシンごとの設定なので、同期はされません。複数の Mac で使うときは、それぞれに書いてください
- データファイルが無いときは、最初にタスクを足した時点で作ります

## AI やスクリプトから読み書きする

アプリはデータファイルを 1.5 秒ごとに確かめ、外で書き換わっていたら読み直します。そのため、AI エージェントにファイルを直接書き換えてもらえば、開いているアプリにもそのまま出ます。

- **入力中・ドラッグ中**: 操作を邪魔しないよう、終わるまで読み直しを待ちます
- **アプリと外の書き込みが重なったとき**: アプリは保存の直前に、読んだときから外で書き換わっていないかを確かめます。書き換わっていたら、アプリ側の保存をやめて外の内容を読み直します。このとき、アプリでの直前の 1 操作は反映されません
- **書き換えるときのお願い**
    - ファイル全体を、正しい JSON として書いてください。書きかけを読まれないよう、一時ファイルに書いてから置き換える（rename する）と安全です
    - アプリが使わないキーは、そのまま残します。外のツールが自分用の情報（読み込み元など）を足してかまいません
    - 足りない項目（`id` や `children` など）は、アプリが読み込むときに補います

AI エージェントに渡すときは、次のような指示で足ります。

> `~/Documents/uragami-todo/todo.json` は uragami-todo のデータです。形は README の「データの形」のとおりです。`tasks` の中だけを書き換え、ほかのキーは残してください。

## データの形

```json
{
  "version": 1,
  "date": "2026-10-19",
  "updatedAt": "2026-10-19T14:20:00.000Z",
  "tasks": [
    {
      "id": "9d0061",
      "title": "ロゴを作る",
      "done": false,
      "tomorrow": false,
      "children": [
        { "id": "a1b2c3", "title": "参考を集める", "done": true, "children": [] },
        { "id": "d4e5f6", "title": "ラフを 3 案描く", "done": false, "children": [] }
      ]
    },
    {
      "id": "61188a",
      "title": "チラシの文言を決める",
      "done": false,
      "tomorrow": true,
      "children": []
    }
  ]
}
```

| キー | 型 | 意味 |
| --- | --- | --- |
| `version` | 数値 | データの形の版です。いまは `1` です |
| `date` | 文字列（任意） | 見出しに出す日付（`YYYY-MM-DD`）です。無ければ「今日のこと」と出します |
| `updatedAt` | 文字列 | アプリが最後に保存した時刻です。アプリが書きます |
| `tasks` | 配列 | タスクの一覧です。配列の順が、そのまま表示の順です |
| `tasks[].id` | 文字列 | タスクの目印です。同じファイルの中で重ならなければ形は自由です。無ければアプリが付けます |
| `tasks[].title` | 文字列 | タスクの名前です |
| `tasks[].done` | 真偽値 | 完了なら `true` です |
| `tasks[].tomorrow` | 真偽値 | 明日に回したら `true` です。一番上の階層のタスクだけが持ちます。`true` のタスクは「明日やる」の欄に出ます |
| `tasks[].children` | 配列 | 子タスクです。`id`・`title`・`done`・`children` を持ち、同じ形で入れ子にできます |

## インストール

署名していないアプリなので、自分でビルドして使います。

```bash
npm install
npm run build
```

`src-tauri/target/release/bundle/macos/uragami-todo.app` ができるので、「アプリケーション」フォルダなどにコピーしてください。ほかの Mac にコピーして初めて開くときは、右クリックの「開く」から起動します。

## 開発

- 必要なもの: Node.js、Rust（[rustup](https://rustup.rs/)）
- `npm run dev` で開発用に起動します
- 画面は `src/`（ビルドなしの HTML / CSS / JS）、ファイルと設定の読み書きは `src-tauri/src/main.rs` です
- アイコンは `app-icon.png` から `npx tauri icon app-icon.png` で作ります

[Tauri 2](https://tauri.app/) で作っています。
